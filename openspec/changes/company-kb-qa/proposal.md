# 变更提案：开公司知识库（随问随答）

## 背景

`/Volumes/wd/开公司` 下已有完整的创业知识资料（301 个文件 / 5.8G）：

- 8 门系统课程（注册公司、财税、股权薪酬、商标、ICP 备案、创业融资、人事合规模板、开公司必备知识）
- 6 大模块合集（创业筹备、成立企业、商业计划、品牌打造、合同协议大全、全国补贴政策）
- 121 集课程视频，合计 20.0 小时，平均 10 分钟/集
- 150 份文档（docx 75 / doc 54 / pdf 17 / xlsx 5 / pptx 1）

现状问题：资料是"文件夹"，不是"知识"。想确认一件事（比如"注册资本认缴制下出资期限怎么填"、"小规模纳税人什么条件下能转一般纳税人"），必须记得它大概在哪门课哪一集，再拖进度条找。视频里的内容无法全文检索，模板文件只有打开才知道讲什么。

## 目标

把这批资料变成可提问、可溯源的知识库：

1. **能问**：用自然语言提问，返回直接结论，而不是一堆文件名。
2. **能溯源**：每条答案标注出处——文档给「文件名 + 章节/页码」，视频给「课程 + 集名 + mm:ss」，可直接跳回原片核对。
3. **能覆盖视频**：视频语音转写 + 画面文字识别，避免"讲师只说了一半、另一半在 PPT 上"的漏检。
4. **入口单一**：直接用对话提问，不需要记命令、开网页、登录系统。

## 范围

- 覆盖：上述全部 301 个文件（文字类 + 全部 121 集视频）。
- 不做：不对视频做剪辑/转码/发布；不替换原始资料；不对外分发内容（后续如需飞书镜像另行立变更）。

## 影响

- 新增 `kb/` 工程目录（解析、转写、索引、检索脚本），数据与索引均落在项目目录内，原始文件不动。
- 新增用户级 Skill `company-kb`，使对话可直接检索。
- 新增 `notes/` 视频笔记产物（每集一份 Markdown，带时间戳）——这本身也是可读的二次资料，即使不用检索也能看。
