# 问答资产库（qa/）

本目录把「开公司」相关的每一次问答沉淀为可检索、可复用的数字资产。

规则见仓库根目录 [`AGENTS.md`](../AGENTS.md) 第 1 节。

---

## 怎么读

- 按日期找：`qa/YYYY-MM-DD/序号-主题.md`
- 按主题找：见下方索引表的「主题」列
- 想系统学：读 [`docs/`](../docs/index.md)，QA 是素材，`docs` 是成稿

## 每条记录包含

问题原文 → 结论 → 关键要点（带数字和门槛）→ 风险与边界 → 可执行动作（电话/网址/材料）→ 出处 → 待核实
