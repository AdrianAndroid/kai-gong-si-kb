## 问题

初步想做抖音小游戏接入广告，想开个公司，现在不是流行一人公司吗？

## 结论

先别注册。先做 1~2 个月产品验证，跑通上线闭环再定主体。若必须先办：只吃广告分成的起步阶段，**个体工商户最省钱**；要拿经开区 0 元免费地址，则**必须公司制**（一人有限公司）。注册资本写 3~10 万，不写 100 万。

## 关键要点

### 一、一人公司：新《公司法》（2024-07-01 生效）三条硬事实

1. **旧法「一个自然人只能设一家一人公司」的限制已删除**；一人公司不再单设一节，并入第 23 条、第 60 条。
2. **举证责任倒置仍保留（第 23 条第三款）**：只有一个股东的公司，股东不能证明公司财产独立于自己财产的，对公司债务承担连带责任。举证责任在股东，需提交经审计的年度财务会计报告、完整账簿、独立银行账户、规范关联交易合同。
3. **注册资本 5 年内必须实缴（第 47 条）**；2024-07-01 前设立的老公司须在 2027-06-30 前把期限调到 5 年内。课程里「认缴 20~30 年」已作废。

### 二、三种主体对比

| | 个体工商户 | 一人有限公司 | 两人及以上有限公司 |
|---|---|---|---|
| 抖音主体类型 | 算企业身份，可创建并备案 | 企业身份 | 企业身份 |
| 责任 | 无限责任 | 有限责任 + 举证倒置 | 有限责任，举证在债权人 |
| 税 | 经营所得 5%~35% | 企业所得税 + 分红 20% 个税 | 同左 |
| 注册资本 | 无 | 认缴，5 年内实缴 | 同左 |
| 经开区免费地址 | **不能用**（个体户无法人资格） | 可以 | 可以 |
| 适合 | 单人试水 | 长期做、要融资或接企业合作 | 有合伙人 |

### 三、抖音小游戏的实际门槛

1. **个人主体基本走不通**：平台明确「企业主体勿选个人开发者，否则未来无法结算」；个人主体目前只能建「小玩法」，不能建小程序类应用。
2. **软著是硬门槛，著作权人必须与平台主体名称完全一致**。先用个人名义申请、后注册公司，需补授权证明。顺序：先定主体，再申请软著。
3. **上架需 ICP 核准**（所有小游戏）+ 小游戏备案；已有版号可跳过备案；**内购必须版号，纯广告变现走备案路径**。
4. **分成**：非投广场景开发者拿广告收入 **60%**，投广场景 **90%**。
5. **结算要开票**：企业开发者开增值税专票，税率不低于 6% 按全额结算，低于 6% 按公式折减；个人开发者结算直接扣个税。小规模只能开 3%，流水上来后一般纳税人更顺。
6. 单周期累计不足 1000 元可暂不结算。

### 四、建议路径

| 阶段 | 动作 | 成本 |
|---|---|---|
| 第 1 个月 | 做 1 个 demo，跑抖音开发者工具，测留存 | 0 |
| 第 2 个月 | 办主体 + 申请软著（普通 1~2 个月）+ ICP 核准 | 几百 |
| 第 3 个月 | 上架、接广告位，看 eCPM 与留存 | 0 |
| 流水稳定后 | 升级一人有限公司，迁移软著/ICP/备案 | 2000~3000 |

### 五、一人公司四条底线

1. 注册资本写小（3~10 万），5 年内要真缴。
2. 公司账户与个人账户绝不混用。
3. 每年做一份审计报告并留存——这是证明财产独立的唯一凭据。
4. 注册地址走官方免费通道，不买「永久地址」。

## 风险与边界

- 一人公司不等于有限责任护身符；账不干净，有限责任失效。
- 抖音小游戏的钱在留存与 eCPM，不在营业执照；未验证就注册是浪费。
- 平台规则会变，准入与分成以开放平台当次公告为准。

## 可执行动作

1. 用两周做三个不同品类 demo，看留存能否过 30%。
2. 确定路线：个体户（便宜，地址自购）或 一人公司（可用免费地址）。
3. 主体定了立刻申请软著（著作权人写主体全称）。
4. 再做 ICP 核准、小游戏备案。
