# 00 新手 30 天路线

> 这一页给**完全新手**：从零开始，按周推进，每步有清单可勾。
> 不需要一次看完所有模块，按路线走到哪一步就看对应模块。

---

## 第 1 周：定方向 + 核名

**目标**：确定企业类型、想好公司名、通过核名。

- [ ] 确定企业类型 → [01-注册登记](01-注册登记/index.md)
  - 不知道选什么 → 默认「有限责任公司」
  - 一人开店且不开发票 → 考虑个体户
- [ ] 准备 3–5 个候选字号（从最想要到最不想要排序）
- [ ] 查询商标是否已被注册 → [05-知识产权](05-知识产权/index.md)
- [ ] 线上提交核名（1 个工作日出结果）
- [ ] 想清楚 6 个核心决策：类型、名称、注册资本、股权比例、地址、经营范围 → [01-注册登记](01-注册登记/index.md)

---

## 第 2 周：注册资本 + 股权比例

**目标**：确定注册资本金额、股权分配方案、签好协议。

- [ ] 确定注册资本 → [01-注册登记](01-注册登记/index.md)
  - 够用即可，需要时再增资
  - 涉及 ICP 许可/天猫入驻 → 至少 100 万
- [ ] 确定股权比例 → [03-股权分配](03-股权分配/index.md)
  - 一定要有人能拍板（避免 50:50、33:33:34）
  - 67% 完全控制 / 51% 相对控制 / 34% 一票否决
- [ ] 准备股东出资协议 / 股权分配协议 → `assets/templates/03-股权分配/`
- [ ] 确定法人、董事、监事、经理人选（监事不能由董事/经理兼任）
- [ ] 确定注册地址（真实、可收信函）

---

## 第 3 周：提交注册 + 刻章

**目标**：拿到营业执照、刻好章。

- [ ] 线上提交登记信息（全部填好）
- [ ] 全体股东电子签名
- [ ] 领取电子营业执照
- [ ] 刻章备案（公章、财务章、法人章、合同章、发票章）
- [ ] 建立用章登记簿

---

## 第 4 周：开户 + 税务报到

**目标**：银行账户开好、税务登记完成、公司可以正常运转了。

- [ ] 银行开基本户（带执照、公章、法人身份证）
- [ ] 税务报到：核定税种、领发票、签三方协议 → [02-财务合规](02-财务合规/index.md)
- [ ] 了解三大税种（增值税、企业所得税、个税）→ [02-财务合规](02-财务合规/index.md)
- [ ] 确定记账方式（自聘会计 / 代账公司）
- [ ] 有员工 → 社保开户 → [04-人力管理](04-人力管理/index.md)
