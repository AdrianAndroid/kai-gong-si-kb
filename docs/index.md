# 开公司 · 新手创业知识库

把「开公司」这件事拆成 **9 个模块、一条路线**，讲清楚每个决策该怎么做、坑在哪、模板去哪拿。

> 内容整理自公开课程（小辉「教你开公司」系列，121 集），全部经过重新组织与校对。
> 原文逐集转写见 [`transcripts/`](transcripts/)，本地可检索的 RAG 工具见 [`tools/`](tools/)。

---

## 从哪开始

- **完全新手** → [新手 30 天路线](00-新手路线.md)：按顺序走，每步都有清单
- **马上要注册公司** → [01-注册登记](01-注册登记/index.md)
- **公司已开、想省钱合规** → [02-财务合规](02-财务合规/index.md)
- **要分股权 / 发激励** → [03-股权分配](03-股权分配/index.md)
- **要招第一个员工** → [04-人力管理](04-人力管理/index.md)

| [03 股权分配](03-股权分配/index.md) | 股权含哪些权利、怎么分不打架、怎么激励又不失控 | 02 课程 14 集 + 01 课程 |
| [04 人力管理](04-人力管理/index.md) | 怎么招人、合同怎么签、五险一金怎么上、离职怎么处理 | 01 课程 + 04 课程社保篇 + 07 模板包 |
