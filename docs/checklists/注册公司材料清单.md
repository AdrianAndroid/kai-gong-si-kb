# 注册公司材料清单

> 打印出来逐项勾。提交注册前对照准备，缺一项就跑不完流程。

---

## 一、必备材料

- [ ] 全体股东身份证原件 + 复印件
- [ ] 法定代表人身份证原件 + 复印件
- [ ] 监事身份证复印件（不能由法人/董事/经理兼任）
- [ ] 注册地址证明（房产证复印件或租赁合同 + 产权证明）
- [ ] 公司名称核准通知书（核名通过后获取）
- [ ] 公司章程（可从工商局模板下载后修改）
- [ ] 股东出资协议 / 股权分配协议（多人股东时必须有）

## 二、信息确认（提交前逐项检查）

- [ ] 公司名称：行政区划 + 字号 + 行业 + 组织形式
- [ ] 企业类型：有限责任公司 / 个体户 / 其他
- [ ] 注册资本：金额 + 各股东认缴额 + 缴付期限
- [ ] 股权比例：加起来 = 100%
- [ ] 经营范围：主营在前，许可项已确认资质
- [ ] 法人、董事、监事、经理信息（监事不兼任）
- [ ] 注册地址：详细到门牌号

## 三、刻章材料

- [ ] 营业执照副本
- [ ] 法人身份证
- [ ] 刻章委托书（如代办）

## 四、银行开户材料

- [ ] 营业执照正副本
- [ ] 公章、财务章、法人章
- [ ] 法人身份证原件
- [ ] 公司章程
- [ ] 租赁合同（部分银行要求）

## 五、税务报到材料

- [ ] 营业执照副本
- [ ] 法人身份证
- [ ] 公章、财务章
- [ ] 银行开户许可证
- [ ] 三方协议（银行、税务、企业）
