# 用工合规自查清单

> 打印出来逐项勾。招第一个员工前对照，避免劳动纠纷。

---

## 一、入职环节

- [ ] 签订**书面劳动合同**（入职 30 天内必须签，否则双倍工资）
- [ ] 合同包含必备条款：期限、工作内容、报酬、社保、劳动保护
- [ ] 约定试用期（合同期 1 年 → 试用期 ≤ 2 个月；3 年 → ≤ 6 个月）
- [ ] 试用期工资 ≥ 约定工资的 80%，且不低于当地最低工资
- [ ] 录用条件已书面明确（试用期解除需有依据）
- [ ] 员工身份证、学历证等基本资料归档

## 二、在职管理

- [ ] **五险一金**按时足额缴纳（入职 30 天内办理社保登记）
- [ ] 工资按时发放，保留银行转账记录
- [ ] 工作时间合规（每日 ≤ 8 小时、每周 ≤ 44 小时）
- [ ] 加班有记录且依法支付加班费
- [ ] 年假安排（累计工作满 1 年 → 5 天起）
- [ ] 规章制度已公示并有员工签收记录

## 三、保密与竞业

- [ ] 涉密岗位签**保密协议**
- [ ] 核心岗位签**竞业限制协议**（离职后按月支付补偿金）
- [ ] 竞业限制期限 ≤ 2 年
- [ ] 竞业限制补偿金标准已明确（一般为离职前 12 个月平均工资的 30%+）

## 四、离职环节

- [ ] 协商解除 / 单方解除的依据合法合规
- [ ] 出具**离职证明**（法定必须）
- [ ] 结清工资、未休年假折算
- [ ] 需要支付经济补偿的情况已明确（N / N+1 / 2N）
- [ ] 社保、公积金减员及时办理
- [ ] 交接手续有书面记录

## 五、高风险红线

| 行为 | 后果 |
|---|---|
| 不签劳动合同 | 从第 2 个月起付双倍工资 |
| 不缴社保 | 员工可随时解除 + 要求补缴 + 经济补偿 |
| 试用期随意辞退 | 违法解除，需付 2N 赔偿金 |
| 女职工三期辞退 | 违法解除，需恢复劳动关系或付赔偿 |
| 无制度依据处罚员工 | 不被仲裁支持 |

> 以上按 2022 年《劳动合同法》口径整理，具体以当年政策为准。
