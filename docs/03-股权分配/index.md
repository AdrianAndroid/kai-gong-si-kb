# 03 股权分配

> 这一模块讲两件事：**股东之间怎么分（股权结构）**，和**员工怎么分（激励机制）**。
> 前者决定公司会不会死在内部斗争上，后者决定团队能不能扛过从 0 到 1。

---

## 一、股权到底包含哪些权利

很多人以为"股权 = 分钱"，实际上它是一束权利，可以拆开单独安排：

| 权利 | 含义 | 实践要点 |
|---|---|---|
| **表决权** | 股东会按比例投票 | 可以约定"同股不同权"（章程另行约定） |
| **分红权** | 按比例分配利润 | 可以约定不按出资比例分红，也可设计"分红权/虚拟股"只给收益不给投票 |
| **知情权** | 查账、查股东会决议 | 小股东常靠这条保护自己 |
| **优先购买权** | 其他股东转让股权时优先受让 | 用于防止外人突然进入 |
| **剩余财产分配权** | 清算时按比例分配剩余资产 | 通常排在公司债务之后 |
| **提案/召集权** | 10% 以上股东可提议召开临时股东会 | 小股东的"发声通道" |

> **关键结论**：控制权和分红权可以分离。给员工激励时，多数场景只需要"分红权 + 增值收益"，**不必给表决权**。

## 二、初创团队分股权的 5 个坑

1. **平均分（50:50 / 33:33:34）** —— 没有最终决策人，第一次分歧就僵死。必须有一个 ≥51%（最好 ≥67%）的核心。
2. **按出资比例分，忽略人力投入** —— 出钱的人拿大头、全职干活的人拿小头，半年后干活的人心理失衡。建议明确"资金股 + 人力股"两部分。
3. **一次性给满，没有成熟期（Vesting）** —— 有人干了 3 个月就走，却带走 20% 股权。标准做法：**4 年成熟、满 1 年成熟 25%，按月线性释放**，未成熟部分公司可回购。
4. **没写退出机制** —— 离职、离婚、去世、继承人继承，都会让股权结构失控。要在股东协议里写清**回购触发条件与价格公式**。
5. **代持** —— 实际出资人让朋友代持，一旦代持人负债、离婚或反悔，股权归属要靠打官司。**必须签书面代持协议 + 出资凭证 + 尽可能还原真实关系**。

**必签的三份文件**：股东协议（约定退出/回购/优先权）、公司章程（可个性化约定表决与分红）、出资协议（明确出资额、方式、时间）。

## 三、员工激励：六种方法怎么选

| 方法 | 给什么 | 适合谁 | 成本与风险 |
|---|---|---|---|
| **实股（直接持股）** | 真实股权，含表决权 | 极少数核心合伙人 | 变动要走工商变更，退出麻烦 |
| **限制性股权** | 先给股，附条件（服务期/业绩） | 核心管理层 | 需成熟与回购条款 |
| **期权（ESOP）** | 未来按约定价格买入的权利 | 中层、技术骨干 | 需期权池（常见预留 10–15%） |
| **虚拟股 / 分红权** | 只分利润，不占注册资本 | 中层、销售负责人 | 不动股权结构，到期可收回 |
| **超额利润分享** | 超出目标利润部分按比例分 | 业务团队 | 简单、灵活、无股权后患 |
| **项目跟投 / 孵化合作** | 单个项目分成或子公司持股 | 独立业务线负责人 | 留不住的人可以"换一种方式合作" |

**分钱的底层逻辑**：先定规则再分钱，而不是年底拍脑袋发红包；让员工知道"做到什么程度能拿多少"，激励才有牵引力。

**配套的薪酬工具**：八大提成方法（按业绩、按毛利、按回款、阶梯提成等）、绩效系数、晋升与调岗机制——这些与股权激励组合使用，才是完整的"科学分钱"体系。

## 四、四个真实案例的共同点

课程里拆解了互联网大厂、连锁培训机构、游戏公司三类方案，共同点很清晰：

- **分层设计**：不同层级用不同工具（高管给股权、中层给分红权、一线给提成）
- **绑定时间**：所有股权类激励都有成熟期与退出条款
- **算得清**：每个人都能自己算出"做到多少拿多少"
- **留后手**：预留期权池、约定回购，避免后期无股可分
